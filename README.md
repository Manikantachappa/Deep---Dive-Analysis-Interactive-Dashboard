# Task 3 - Deep-Dive Analysis & Interactive Dashboarding

## Project Overview
This project focuses on performing a deep-dive business analysis and building an interactive dashboard using Power BI. The main objective is to define core KPIs, analyze important business segments, and present the findings in a clear visual dashboard for decision-making. [cite:1]

## Objective
The objective of this project is to solve a complex business problem by:
- Defining 3 to 5 core KPIs
- Performing a deep-dive analysis on one business area
- Building an interactive dashboard in Power BI
- Highlighting business insights through visual storytelling [cite:1]

## Dataset Used
The dataset used for this project contains sales transaction data with the following fields:
- OrderID
- OrderDate
- CustomerID
- Gender
- Age
- ProductCategory
- ProductName
- Quantity
- Price
- TotalAmount
- City
- PaymentMethod [file:104]

## KPIs Defined
The following KPIs were created for the dashboard:

1. **Total Sales** = Sum of `TotalAmount`
2. **Total Orders** = Count of `OrderID`
3. **Total Customers** = Distinct count of `CustomerID`
4. **Average Order Value** = Total Sales / Total Orders
5. **Average Quantity** = Average of `Quantity` [cite:1]
